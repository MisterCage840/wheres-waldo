**🕵️ Where’s Waldo – Full Stack Photo Tagging Game**
<img width="1194" height="725" alt="image" src="https://github.com/user-attachments/assets/615269b6-6bca-45da-be8e-d246492959f9" />



A full-stack “Where’s Waldo” style game built with:

Frontend: React (Vite)

Backend: Express.js

Database: PostgreSQL

ORM: Prisma

**🎮 Features**

🖼 Multiple game images selectable from dropdown

🎯 Click-to-target selection box

✅ Server-side validation

📍 Marker placement on correct guesses

⏱ Server-side timer tracking

🏆 High score leaderboard per image

🍪 Anonymous session tracking via cookies

📐 Normalized coordinate system (resolution independent)

**🚀 Running the Project**
Backend
cd server
npm install
npx prisma migrate dev
npx prisma generate
npm run seed
npm run dev


Backend runs on:

http://localhost:5000

Frontend
cd client
npm install
npm run dev


Frontend runs on:

http://localhost:5173
